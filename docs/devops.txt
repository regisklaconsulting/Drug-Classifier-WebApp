Before all, we need to containerize the web app any time we ear abot depeloyment. Thus let us add a Dockerfile and test if

Build Docker image and tag it: 

(...)$ docker build -t drug-classifier-webapp-img:1.0.0 .
(...)$ docker tag drug-classifier-webapp-img:1.0.0 drug-classifier-webapp-img:latest 

>>> Run the app as a container: 

(from the project top directory)

- Run: 

$ mkdir -p /tmp/models && cp ../Drug-Classifier/model/drug-classifier-pipeline.skops /tmp/models 
$ docker run --rm -t \
    -v /tmp/models:/models \
    -e MODEL_FILE_PATH=/models/drug-classifier-pipeline.skops \
    --name drug-classifier-webapp  \
    drug-classifier-webapp-img:latest

Get IP address of the container:

$ docker inspect -f '{{range.NetworkSettings.Networks}}{{.IPAddress}}{{end}}' drug-classifier-webapp
172.17.0.2

Then browse: http://172.17.0.2:7860/

See [drug-classifier-gradio-gui.png] for an example of the web app.

>>> Step 4: Push the prediction pipeline to HF Space 

We will manually execute the Makefile using env variables set on the command line: 

Copy the model somewhere: 

$ mkdir -p /tmp/models && cp ../Drug-Classifier/model/drug-classifier-pipeline.skops /tmp/models

Push the model in HF space: 

$ export HF_TOKEN="xxxxxxxxxxxxxxxxx" 
$ export HF_REPO_ID="regisklaconsulting/Drug-Classifier-Web-App" \
    export MODEL_LOCAL_PATH="/tmp/models/drug-classifier-pipeline.skops" \
    export MODEL_REMOTE_PATH="/models/drug-classifier-pipeline.skops"
$ make deploy HF_TOKEN=$HF_TOKEN HF_REPO_ID=$HF_REPO_ID MODEL_LOCAL_PATH=$MODEL_LOCAL_PATH MODEL_REMOTE_PATH=$MODEL_REMOTE_PATH 

Go to your HF space, and check the "Files" tab to see if the models/ directory is created and populated. 

Now update the Dockerfile with the following line, and push it: 

...
WORKDIR /app
...
COPY models/. /app/models/
...

Build the image locally and test it (without mounting any directory, nor specifying the MODEL_FILE_PATH env var): 

$ docker build -t drug-classifier-webapp-img:1.0.0 . 
$ docker tag drug-classifier-webapp-img:1.0.0 drug-classifier-webapp-img:latest
$ docker run --rm -t \
    --name drug-classifier-webapp  \
    drug-classifier-webapp-img:latest
